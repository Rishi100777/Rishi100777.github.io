# Rishi Patel — Personal Portfolio

A responsive personal portfolio introducing my finance and statistics background, technical skills, and selected projects.

## Website sections

- **Personal statement:** a one-sentence introduction.
- **Skills:** programming and data, finance and analysis, and tools and collaboration.
- **Projects:** Monte Carlo Options Simulation and Market Risk Analysis, each with a description and a public code link.

## Technology

Semantic HTML and responsive CSS, with no build step or external dependencies. Includes keyboard focus styles, a skip link, reduced-motion support, and a custom favicon.

## Local preview

Open `index.html` in a browser, or run `python -m http.server 8000` from this directory and visit `http://localhost:8000`.

## GitHub Pages publishing

In the public repository, open **Settings → Pages**. Choose **Deploy from a branch**, select **main** and **/(root)**, and save. The repository root contains `index.html` and `.nojekyll`.
